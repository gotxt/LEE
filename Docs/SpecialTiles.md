# 공용 특수 타일 — 덩굴 / 불

2026-09-28. Unity 6000.5.3f1. 기존 일회용 POWER/MUD 아이템과 별개인, 밟아도 없어지지 않는 전장 배치 레이어다.

2026-10-02 변경: 공용 불은 **처음에는 꺼져 있으며 성공한 경로 공격에 포함되면 30초간 점화**된다. 아래 ‘모닥불 점화’ 절이 과거의 즉시 충전 설명보다 우선한다. 사용자의 지시에 따라 패턴 에디터 코드는 변경하지 않았다.

## 팀원용 사용법

1. Boss Encounter Editor에서 보스를 열고 왼쪽 **특수 타일 배치**를 선택한다.
2. 팔레트에서 **덩굴** 또는 **불**을 선택한다. 종류는 `SpecialTileDefinition` 에셋을 자동으로 검색한다.
3. **타일 칠하기**로 바닥을 클릭·드래그한다. 같은 칸을 다시 칠하면 교체된다. **지우개**, 우클릭, Shift+드래그로 지우고 Ctrl+Z로 한 획을 되돌릴 수 있다.
4. 상단 **저장**을 누른다. 배치는 보스 데이터의 `arena.specialTiles`, 효과와 이미지는 공용 `TileData_*.asset`에 저장된다.
5. **시험 시작 위치**로 P를 놓고 방향 버튼이나 **한 칸 이동 시험**으로 인접 타일을 클릭한다. 불 잔량·기절 시간을 확인한다. 이 시험은 저장된 스폰과 START/END를 바꾸지 않는다. **시험 초기화**로 다시 시작한다.

부패화에만 쓸 수 있는 기능이 아니다. 어느 보스에서든 같은 타일을 선택하고 배치할 수 있다. 이번 작업은 도구/타일 데이터를 추가했으며 기존 보스 맵에 임의의 타일을 배치하지 않았다.

## 효과와 수치

| 데이터 | 기본 효과 |
|---|---|
| `Assets/Resources/SpecialTiles/TileData_Vines.asset` | 진입할 때마다 이동 1초 정지. 통과 가능한 바닥이며 서 있는 동안 재발동하지 않음 |
| `Assets/Resources/SpecialTiles/TileData_Fire.asset` | 성공한 공격 경로에 포함되면 30초 점화. **켜진 동안 진입**하면 발에 다음 20칸의 불 부여. 다시 밟으면 이동 잔량 갱신. 접촉 피해 없음 |

- **불 지속 이동 칸 수**를 편집하면 20을 다른 값으로 바꿀 수 있다. **진입 시 기절 (초)**도 편집 가능하다. 0인 효과는 적용하지 않으며 두 효과를 조합한 타일도 만들 수 있다.
- 공용 데이터 수정은 같은 에셋을 참조하는 모든 보스에 적용된다. 특정 보스에서만 다른 값을 쓰려면 **선택한 특수 타일 데이터 복제** 후 복제본으로 칠한다.
- 바닥/보스 점유 밖에는 배치할 수 없다. START/END에는 배치 가능하다. 바닥 이미지나 이동 가능성을 바꾸지 않는다. 맵 축소/바닥 삭제 후 잘못된 배치는 오류로 표시하므로 직접 지운다.
- 이미지가 없으면 색상과 V/F 기호를 작은 모서리 표식으로 표시한다. 전용 그림은 **표시 이미지**에 Sprite를 지정한다. 이미지가 있으면 게임에서 바닥 한 칸 크기로 중앙에 겹쳐 그리며 원래 투명 영역으로 바닥이 보인다. 플레이어 상태 색과 HP 옆 불 잔량/기절 시간은 별개다.
- 배치한 특수 타일은 패턴 종료/경로 초기화/START·END 갱신으로 사라지지 않는다. 모든 페이즈에서 같은 배치를 사용한다. 사망·전투 재시작 시 플레이어 상태를 초기화하고 배치를 다시 로드한다. 허브/튜토리얼/클리어/컴포넌트 종료 시 정리한다.

## 모닥불 점화 — 2026-10-02

1. 기존 특수 타일 칠하기로 **불 / TileData_Fire**를 원하는 바닥에 배치한다. 이번 작업에서 저장된 보스 맵에 불 위치를 임의로 추가하지 않았다.
2. 게임 시작 시 꺼진 모닥불이다. START→END 경로에 해당 칸을 포함하고 공격을 성공시키면, 공격 성공 처리 시 경로 안의 불 타일들이 함께 켜진다. START/END에 놓인 불도 포함된다. 미완성 경로·경로 초기화·보스의 공격은 점화하지 않는다. 광폭화 피해 면역처럼 보스 체력이 줄지 않는 경우에도 유효한 경로 공격이면 점화한다.
3. 점화 시간은 각 배치별로 30초다. 켜진 불을 포함한 공격에 다시 성공하면 **그 시점부터 30초로 갱신**한다(시간 합산 아님). 경로 공격 연출의 입력 잠금/일시정지 동안 멈추고 덩굴 기절 중에는 진행하는 기존 전투 시간 기준이다.
4. **켜진 타일에 이동해서 들어올 때** 발에 불을 붙인다. 기본 20칸 동안 여러 미성장 씨앗을 지우고 재접촉하면 20칸으로 갱신한다. 꺼진 타일은 충전하지 않는다. END의 이동 접촉은 공격 성공보다 먼저이므로 END의 불이 방금 켜져도 자동 충전하지 않으며 나갔다가 다시 들어와야 한다. 가만히 서 있는 동안 켜지는 경우에도 자동 충전하지 않는다.
5. 30초 뒤 모닥불은 꺼지지만 **이미 발에 붙은 불의 이동 잔량은 유지**한다. 완전 성장체는 여전히 파괴할 수 없다. 덩굴이 덮으면 불의 점화/충전이 모두 불가능하다. 가려진 불도 시간은 흐르므로 덩굴 제거 후 과거의 점화 시간을 되살리지 않는다.
6. 같은 전투의 일반 패턴/라운드/체력 페이즈 전환은 고정 불의 남은 시간을 유지한다. 동적 타일은 각 lease에 독립 상태를 소유하며 새로 배치한 불은 꺼진 상태다. 사망·재시작·클리어·종료는 타이머와 발의 불을 정리한다.

이미지:

- `Assets/Resources/Art/SpecialTiles/TileSprite_CampfireActive.png`: 켜진 불.
- `Assets/Resources/Art/SpecialTiles/TileSprite_CampfireInactive.png`: 꺼진 모닥불.
- 두 PNG는 사용자 원본을 수정 없이 복사했다. 전체 32×32 캔버스, 중앙 pivot, 32 PPU, Point 필터, 비압축, mipmap 없음. 두 그림의 투명 여백을 동일하게 유지하므로 점화/소등 시 장작의 위치와 배율이 바뀌지 않는다. 바닥 그림을 교체하지 않고 그 위에 투명한 Sprite를 겹친다. 경고는 기존 상위 레이어다.

설정 변경과 에디터 제한:

- Project에서 `Assets/Resources/SpecialTiles/TileData_Fire.asset` 선택 → 기본 Inspector의 **Requires Completed Attack**(켜짐), **Activation Seconds**(30), **Inactive Sprite**(꺼진 그림), **Sprite**(켜진 그림)를 수정한다. **Fire Move Count**(20)는 기존 보스 에디터에서도 수정할 수 있다. 공유 데이터이므로 같은 에셋을 쓰는 모든 보스에 영향을 준다.
- `Requires Completed Attack`을 끄면 이전처럼 항상 활성인 접촉 타일이다. 기존 덩굴과 이전 사용자 정의 타일은 이 옵션이 기본 꺼짐이므로 기존 동작을 유지한다.
- **Boss Encounter Editor의 배치/이동 시험/기믹 프리뷰는 수정하지 않았다.** 배치 격자에는 기존 `Sprite`(켜진 모닥불)와 색을 표시하므로 런타임의 활성 상태를 뜻하지 않는다. 이동 시험에는 경로 공격에 의한 점화·소등 시뮬레이션이 없고, 새 불 데이터는 비활성이므로 여기서는 충전되지 않는다. 실제 배치 후 Play Mode에서 경로 공격으로 확인한다. 시험을 위해 공용 불의 옵션을 끄고 저장하면 게임 규칙까지 바뀌므로 권장하지 않는다.

## 덩굴 이미지 — 2026-09-30

- 공용 `TileData_Vines`에 `Assets/Resources/Art/SpecialTiles/TileSprite_StunThornVines.png`를 연결했다. 사용자 제공 64×64 PNG를 수정 없이 복사했고, Point 필터·비압축·mipmap 없음·중앙 pivot으로 사용한다.
- 예시처럼 그림이 타일 면을 채우도록 Sprite 영역에서 바깥 투명 여백만 제외한다. 원본 PNG는 그대로 두고 `(5,9,55,46)` 영역을 바닥 한 칸의 가로/세로에 맞춰 표시한다. 내부 투명 영역은 유지되며 인접 타일까지 넘치거나 아이템처럼 맥동하지 않는다. 고정 배치와 구역 성장으로 만들어지는 덩굴 모두 같은 이미지를 사용한다. 초록색 아이콘 배경이나 V 문자는 게임의 이미지 위에 추가하지 않는다.
- `표시 색`과 `이미지 없을 때 기호` 값은 유지되어 이미지 제거 시 기존 대체 표시로 돌아간다. 특수 타일 편집기의 기존 색상 오버레이는 그대로이며 에디터 코드 변경은 없다. 이 덩굴 적용 당시에는 이미지 없는 불 타일을 유지했으며, 현재 불 이미지는 위 2026-10-02 절을 따른다.
- 매 칸 1초 기절, 씨앗 성장/덩굴화 조건, 불 이동 거리, 보스의 맵·패턴은 변경하지 않았다.

## 이동과 시간의 정확한 의미

- 활성화된 불 타일에 진입한 직후 잔량은 설정값 그대로다. 그 다음부터 **성공한 상하좌우 한 칸 이동마다** 1을 차감한다. 벽 충돌, 잘못된 방향, 기절 중 입력, 가만히 기다리기는 차감하지 않는다. 경로 중복으로 기록이 초기화되어도 이동에 성공했다면 차감한다.
- 남은 1칸으로 이동한 **도착 지점까지** 불이 유효하다. 도착 판정 후 잔량은 0이다. 다음 이동부터 불이 없다. 켜진 불 타일로 돌아오면 다시 설정값으로 갱신한다.
- 덩굴 한 칸 진입 → 1초 기절 → 다음 덩굴 칸 진입 → 다시 1초 기절. 불이 있다고 덩굴 기절이 면제되거나 덩굴이 타서 없어지지는 않는다.
- 기절 시간은 scaled gameplay time이다. `inputLocked`인 경로 공격 연출 중에는 멈춘다. 기절 자체는 보스 공격/기믹 시간을 멈추지 않는다. 보스 패턴과 겹쳤을 때의 실제 난이도는 플레이로 확인해야 한다.
- 특수 타일 위에 스폰하거나 시험 P를 직접 배치하는 것은 '이동 진입'으로 취급하지 않는다. 다른 칸에서 걸어 들어올 때 발동한다.

## 개발 확장 지점

- `SpecialTileDefinition`: 공용 설정, `SpecialTilePlacement`: 보스 맵의 좌표와 에셋 참조. 런타임 잔량/타이머는 에셋에 쓰지 않는다.
- `SpecialTileField.OnCompletedAttack` / `Advance` / `IsActive` / `SpriteAt`: 각 배치/레이어의 활성 기한과 그림을 관리한다. 실제 게임에서 성공한 경로 공격 처리 후 알리고 게임 시간으로 진행한다. `SpecialTilePlayerState.Enter(..., activated)`에 해당 칸의 활성 여부를 전달하며, 기존 인자만 사용하는 호출은 공격 점화형을 비활성으로 취급한다. 이전 항상 활성형은 그대로 동작한다. 특정 보스 ID나 불 에셋 이름 분기는 없다.
- `SpecialTilePlayerState`: 이동 성공 시 효과와 불 차감, 게임 시간으로 기절 진행. `PlayerTileStep.HasFireOnArrival`은 마지막 유효 이동까지 반영한다. 씨앗 제거에서는 이동 후 `FireMovesRemaining > 0`만 검사하면 마지막 한 칸을 놓치므로 이 플래그를 사용한다.
- `BossMechanicRuntime.OnPlayerStep`: END 경로 공격 시작 전에도 전달되는 공통 이동 알림. [구역 씨앗 성장 기믹](RegionGrowthMechanic.md)은 여기서 미성장 씨앗 제거를 판단한다. 구역 덩굴화가 불을 덮으면 재충전은 사라지지만 이미 남은 불 이동 거리는 유지된다.
- 선택적 `ISpecialTileHost.PlaceSpecialTiles(tile, cells)`: 기믹이 공용 타일 효과를 동적으로 배치할 수 있다. 반환된 lease를 기믹이 보유하고 종료 때 Dispose한다. 겹친 곳은 마지막 살아 있는 배치가 우선하며 제거 시 이전 배치가 복원된다. 바닥 밖/보스 점유칸은 제외된다. 배치 순간에는 서 있는 플레이어에게 접촉 효과를 발동하지 않는다.
- 런타임과 `PatternPreviewHost` 모두 위 인터페이스를 제공한다. 패턴 미리보기에는 배치 표시가 경고보다 아래에 그려진다. 플레이어를 클릭해서 순간이동시키는 기존 패턴 미리보기와 실제 이동 효과 시험은 구분한다. 성장 기믹 화면에서는 씨앗/덩굴/불/기절을 함께 시험할 수 있지만 일반 공격까지 동시에 재생하지는 않는다.
