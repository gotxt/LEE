# 구역 씨앗 성장 기믹

2026-09-28 · Unity 6000.5.3f1. 보스 ID에 의존하지 않는 `RegionGrowthMechanic`이다.

## 팀원용 편집

1. Boss Encounter Editor에서 부패화 → Phase → **구역 씨앗 성장**을 선택한다. 다른 보스에는 해당 페이즈의 **+ 기믹 추가 → 구역 씨앗 성장**으로 추가한다.
2. **씨앗 생성 구역**을 체크한다. 영역 자체는 왼쪽 **보스 공통 영역**에서 이름과 타일을 칠한다. 연결은 이름이 아닌 안정적인 ID로 저장된다. 성장 구역끼리 타일이 겹치면 오류다.
3. 첫 생성 시간, 반복 간격, 한 번에 총 생성 개수, 성장 시간, 덩굴화 비율, 덩굴화 특수 타일을 편집한다. 부패화 초기값은 **5초 / 5초 / 5개 / 20초 / 0.3 / TileData_Vines**다.
4. 광폭화 조건에는 ‘선택 구역 모두’와 ‘선택 구역 중 하나’가 있다. 두 묶음은 **OR**, 빈 묶음은 조건 없음이다. 부패화는 **꽃잎 6개 모두 OR 중앙 1개**다. 생성 후보는 중앙까지 7개다.
5. **특수 타일 배치**에서 불을 직접 칠한다. 자동으로 불을 배치하지 않았다. 공유 불 데이터의 **불 지속 이동 칸 수** 기본값은 20이며 수정/복제할 수 있다.
6. 씨앗 성장 중/완전 성장 외형에 UI 프리팹 또는 Sprite를 넣는다. 미지정 상태는 노랑/보라 사각형이다. 전용 아트·보스 애니메이션은 이번 작업에 포함하지 않았다.
7. 기믹 화면에서 재생 또는 **+1초 / +5초**로 진행한다. 인접 칸 클릭/화살표로 이동하며 불·씨앗 제거·기절을 시험한다. ‘시험 위치 직접 놓기’는 순간이동이고 접촉 효과를 발동하지 않으며 기존 불/기절을 초기화한다. ‘초기화’는 씨앗·덩굴·광폭화를 모두 초기화한다.
8. 저장한다. 설정 변경 및 Undo 시 미리보기가 초기화된다. 미리보기는 선택 기믹만 실행한다. 정상 전투의 모든 공격과 함께 실행되는 것은 아니다.

2026-09-28 추가: 완전 성장체 주변 공격은 [기믹 출력 위치 호출](MechanicOutputs.md)로 만들 수 있다. 보스 패턴에서 성장 기믹 → **완전 성장체 위치** → 자식 패턴을 선택한다. 미성장 씨앗은 대상에 포함되지 않는다. 이 호출이 있는 패턴의 미리보기에서는 기믹과 선택 패턴을 함께 실행할 수 있다.

## 정확한 규칙

- 매 생성 시 빈자리가 있는 후보 구역을 균등 추첨한 다음, 그 구역의 빈 칸 하나를 균등 추첨한다. 이를 총 생성 개수만큼 반복한다. 구역별로 5개가 아니다.
- 한 칸에 씨앗 하나. 현재 플레이어 칸, 바닥 밖, 보스 점유칸, 임시 이동 차단 칸은 생성에서 제외한다. 공간이 부족하면 가능한 만큼만 생성하며 나머지를 예약하지 않는다. START/END와 불 타일은 통과 가능한 바닥이므로 생성 가능하다.
- 후보 구역의 원래 유효 바닥 수를 시작 시 고정한다. **완전 성장 개수 ≥ ceil(바닥 수 × 비율)**이면 구역 전체를 덩굴화한다. 임시 벽은 분모를 줄이지 않는다. 영역 밖에는 씨앗을 생성하지 않는다. 구역의 중복 타일 항목은 한 칸으로 센다.
- 부패화 기준: 위 34/112, 우상 35/114, 우하 36/118, 아래 32/106, 좌하 36/118, 좌상 35/114, 중앙 20/64.
- 씨앗 생성·성장은 scaled gameplay time이며 경로 공격 연출의 `inputLocked` 동안 멈춘다. 덩굴 기절 중에는 계속 진행한다. 큰 프레임에서도 생성/성장 시각 순서대로 계산하며 같은 시각에는 성장을 먼저 처리한다.
- 불을 가진 채 **이동하여 도착**하면 미성장 씨앗만 제거한다. 불의 마지막 1칸까지 유효하고 남은 거리 안에서는 여러 씨앗을 제거할 수 있다. 일반 경로 공격에 씨앗을 포함하는 것은 제거 조건이 아니다.
- 완전 성장체는 제거할 수 없지만 계속 통과 가능하다. 씨앗 자체는 공격/기절/이동 차단을 하지 않는다. 체력 1 보호도 없다.
- 덩굴화는 한 번 발생하면 해당 기믹이 끝날 때까지 유지된다. 모든 칸을 덮으므로 **불도 덩굴로 바뀌고 재충전 기능이 없어진다**. 이미 발에 붙은 불의 남은 거리를 즉시 지우지는 않는다. 덩굴은 불로 제거되지 않는다.
- 덩굴이 생성되는 순간 가만히 선 플레이어를 즉시 기절시키지는 않는다. 다음 이동 도착부터 매 칸 1초 기절한다. 생성·성장은 광폭화 이후에도 계속된다.

## 광폭화와 이후 패턴 제작

광폭화는 같은 체력 페이즈 내부의 전투 상태다. 성장 기믹 자체는 체력을 회복하거나 씨앗/덩굴을 지우지 않는다. HUD에 `[광폭화]`를 표시하고 `combat.enraged` 신호를 한 번 발생시킨다. 현재 실행 중인 주 공격/배경 공격은 정상 종료하며 **다음 자동 선택**부터 조건을 적용한다.

2026-09-29 후속: 현재 부패화에는 별도 [광폭화 생존전 기믹](EnrageSurvival.md)이 함께 연결되어 있다. 광폭화 진입 때 남은 체력에 60을 더하고 경로 공격 피해를 차단하며, 이후 전투 시간 1초마다 체력이 1씩 감소한다. 0이 되면 생존한 플레이어가 클리어한다. 이 체력 규칙은 생존전 기믹을 사용한 페이즈에만 적용한다.

패턴 편집 상단 **자동 실행 조건**:

- **항상**: 일반/광폭화에서 모두 선택. 기존 데이터의 기본값이다.
- **광폭화 전**: 광폭화 전까지만 자동 선택.
- **광폭화 후**: 광폭화한 뒤에만 자동 선택.

반복 배경 패턴도 같은 조건을 사용한다. 재사용 패턴의 직접 호출과 단일 패턴 미리보기는 이 조건을 무시한다. 호출 주체가 실행 시점을 결정하기 때문이다. 성장 기믹은 새 광폭화 공격, 가속 값, 자동 패배를 만들지 않는다. 실제 패턴 조건은 현재 보스 에셋을 확인한다. 조건에 맞는 패턴이 없으면 주 공격 없이 기다리고 기믹은 계속 실행된다. 생존전 기믹이 켜져 있으면 이때도 체력 카운트다운은 계속된다.

**회피 주의:** 현재 저장된 꽃잎 경고 2.5초는 덩굴의 매 칸 1초 기절을 고려해 조정된 값이 아니다. 실제 통로가 연결되어 있어도 타격 전에 빠져나오지 못할 수 있다. 새로운 공격은 덩굴 상태에서 실제 이동 시간까지 검증해야 한다. `ensureEscape`와 경로 연결성만으로 회피 가능성을 보장하지 않는다.

## 수명과 확장

- `BossMechanicSession`이 씨앗 표시와 덩굴 lease를 소유한다. 일반 주 패턴 교체/START·END 갱신/광폭화에서는 유지한다. 사망·전투 재시작·클리어·정상 체력 페이즈 전환·컴포넌트 종료에는 정리한다. 덩굴 레이어가 제거되면 그 아래 고정 불 배치가 복원된다.
- `BossMechanicRuntime.IsEnraged`는 다른 기믹에서도 제공할 수 있는 공통 신호다. 게임은 기믹 종류나 보스 ID를 비교하지 않는다.
- `PlayerTileStep.HasFireOnArrival`, `IEncounterRegionHost`, `ISpecialTileHost`, `IMechanicPresentationHost`를 재사용한다. 런타임 개수/타이머/광폭화 상태는 보스 에셋에 기록하지 않는다.
- 실제 검사 결과와 수동 미검증 항목은 [현재 패턴 목록](PatternHandoff/CurrentPatternCatalog.md)의 최신 성장 기믹 절을 참조한다.
