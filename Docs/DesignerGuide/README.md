# 수정 봉인 편집 가이드

2026-09-22 파일명 안내: 보스 데이터는 `BossData_CrimsonGolem`, 수정 프리팹은 `MechanicVisual_CrystalSeal`로 변경되었습니다. 기존 화면 캡처에 옛 파일명이 보이면 [에셋 이름 대응표](../AssetNaming.md)를 참고하세요. 에디터의 기믹 표시 이름은 그대로입니다.

디자이너 팀원을 위한 화면 중심 사용법입니다. Unity **6000.5.3f1**, 2026-09-20의 프로젝트와 에디터를 기준으로 작성했습니다.

## 보는 방법

- **[음성 안내가 있는 브라우저 가이드](CrystalSealGuide.html)**: 파일을 Chrome 또는 Edge에서 엽니다. 인터넷 연결 없이 사용할 수 있습니다. 목차로 원하는 단계를 고르고 재생 버튼을 누르면 한국어 합성음성으로 설명합니다. `음성이 끝나면 다음 장으로`를 켜면 순서대로 진행합니다. 인쇄 버튼으로 PDF 저장도 가능합니다.
- **[PowerPoint 가이드](CrystalSealGuide.pptx)**: 팀 교육이나 설명 문구를 고칠 때 사용합니다. 제목과 설명은 편집할 수 있습니다. 실제 에디터 화면은 이미지입니다. 상세 설명은 발표자 노트에도 있습니다.

HTML 파일 하나만 전달해도 화면과 음성이 함께 전달됩니다. 온라인에 게시하거나 공개 링크를 만든 자료는 아닙니다.

## 가장 자주 하는 작업

| 하고 싶은 일 | 에디터에서 할 일 |
|---|---|
| 기존 수정 봉인 열기 | `Trace Strike > Patterns > Boss Encounter Editor`, 대상 보스의 `PHASE 2 > ◆ 수정 봉인` |
| 1페이즈에 추가 | 해당 페이즈 아래 `+ 기믹 추가 > 수정 봉인`. 수정 배치와 공격 연결을 완료합니다. |
| 개수 늘리기 | `수정 추가`를 선택하고 서로 다른 바닥을 클릭합니다. 숫자로 개수를 입력하는 칸은 없습니다. |
| 위치 옮기기 | `선택/이동`, 수정 클릭, 빈 바닥 클릭 |
| 개수 줄이기 | `삭제` 또는 해당 수정 우클릭. 실수하면 Ctrl+Z |
| 공유 공격 수정 | `공통 공격 편집`. 같은 공격을 사용하는 수정에 함께 적용됩니다. |
| 하나의 수정만 변경 | 수정 선택, `이 수정만 별도 공격으로 복제`, `이 수정의 공격 편집` |
| 공격 모양 변경 | `간편 공격 설계`, 공격 선택, 위치 기준 `기믹 / 호출 위치`, 영역 칠하기 |
| 공격 속도 변경 | `첫 공격 대기 (초)`, `반복 주기 (시작→시작)`. 반복 주기는 공격의 전체 재생 시간 이상 |
| 규칙 확인 | `시험 경로`로 모든 수정 칸 선택 후 큰 피해 공격. 처음은 HP 1, 다시 공격하면 HP 0 |

## 꼭 알아둘 규칙

- 수정은 통과할 수 있습니다. 단순히 밟거나 경로를 취소하면 해제되지 않습니다. START에서 END까지 완성한 공격 경로에 포함되어야 해제됩니다.
- 사용하는 수정 봉인에는 최소 1개의 수정이 필요합니다. 해당 페이즈에서 기믹을 쓰지 않을 때는 `기믹 사용`을 끄거나 기믹을 삭제합니다.
- 활성 수정이 남아 있으면 그 페이즈 HP는 최소 1입니다. 마지막 수정을 해제한 공격에도 보호가 유지되고, 다음 공격부터 HP 0과 페이즈 전환 또는 처치가 가능합니다.
- 모두 해제했다고 HP가 자동으로 1이 되거나 보스가 바로 죽지는 않습니다.
- `수정 봉인 0/5`는 **해제한 수/전체 수**입니다. 전부 해제하면 5/5입니다.
- `이 수정의 공격 편집`만 누르면 공유 공격을 그대로 열 수 있습니다. 독립적으로 바꾸려면 먼저 복제하세요.
- 프리뷰의 장치와 효과는 색 표시입니다. 실제 외형, 효과음, 다른 보스 공격과의 조합은 정상 전투에서 확인합니다. 시험 경로는 START/END 연결을 검사하지 않습니다.
- 상단 `저장` 전에 작업 대상과 다른 에셋의 변경 내용도 확인합니다. 현재 저장 버튼은 다른 변경 에셋도 함께 저장할 수 있습니다.

## 화면 예시의 범위

실제 프로젝트를 복사한 별도 연습 사본에서 에디터 화면을 캡처했습니다. 원본의 맵, 스폰, START/END 영역, 보스 외형, 패턴, 기믹 설정은 변경하지 않았습니다. 가이드 속 6개 수정 배치와 개별 공격 복제는 학습용 예시입니다. 현재 원본의 배치를 뜻하지 않습니다.

내용을 더 깊게 확인하려면 [수정 봉인 상세 문서](../BossMechanics.md), [간편 공격 설계](../AttackDesigner.md), [패턴 제작 가이드](../PatternHandoff/PatternAuthoringGuide.md)를 참고하세요. 오래된 문서의 맵 크기나 좌표보다 현재 프로젝트 에셋을 우선합니다.

## 제작 시 확인한 범위

- PPT 14장을 최종 파일에서 다시 불러와 렌더링하고, 글자 잘림과 겹침을 확인했습니다. 구조·레이아웃·폰트 검사에서 오류와 경고가 없었습니다.
- 브라우저에서 목차, 키보드 장 이동, 화면 확대, 음성 재생·일시정지, 음성 종료 후 다음 장 자동 진행을 확인했습니다. 14개 음성은 총 약 4분입니다.
- 별도 Unity 사본의 기믹 미리보기에서 마지막 해제 공격 후 HP 1, 다음 공격 후 HP 0을 직접 확인했습니다. 이 확인은 정상 전투 전체에 대한 통합 테스트를 대신하지 않습니다.
- PowerPoint 데스크톱에서 직접 열기와 브라우저의 실제 PDF 출력은 검증하지 않았습니다. 이번 작업에서는 게임 코드·에셋을 수정하거나 컴파일·직렬화·Undo 회귀 테스트를 새로 수행하지 않았습니다.
