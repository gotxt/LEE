# 광폭화 생존전

2026-09-29 · 부패화의 현재 페이즈에 `EnrageSurvivalMechanic`을 추가했다. 다른 보스에도 같은 기믹을 추가해 사용할 수 있다.

## 전투 규칙

- 광폭화 진입 때 **남은 체력 + 60**으로 바뀐다. 최대 체력도 60을 늘려 상한에 잘리지 않게 한다. 한 번만 적용된다.
- 예: 40/150에서 진입하면 100/210이 되고 **100초의 전투 시간**을 버티면 된다. 전 체력이 남아 있으면 210초다. `@`는 광폭화 직전 남은 체력이다.
- 광폭화 후에는 플레이어의 경로 공격으로 보스 체력이 감소하지 않는다. 경로 완성, 기믹의 경로 접촉 알림, START/END 재생성은 기존대로 동작한다.
- 진입 시점을 기준으로 1초마다 1씩 감소한다. 진입 직후 바로 1을 차감하지 않는다. 소수 시간은 누적하고 프레임이 길면 지나간 감소 횟수를 반영한다.
- 경로 공격 연출 등 `inputLocked` 동안에는 패턴·성장과 함께 카운트다운이 멈춘다. 덩굴의 이동 기절 중에는 계속 흐른다. 게임의 scaled time을 사용하므로 `Time.timeScale=0`에서도 멈춘다. 현실 시계 기준의 60+@초와는 다를 수 있다.
- 체력이 0이면 플레이어의 마지막 공격 없이 자동으로 처치 처리한다. 마지막 체력 페이즈인 부패화는 즉시 STAGE CLEAR가 된다. 다른 보스의 중간 페이즈에 붙였다면 기존 다음 체력 페이즈로 전환한다.
- 같은 프레임에 플레이어 피격이 확정되었다면 사망을 우선하여 클리어로 바뀌지 않게 한다. 사망·재시작·페이즈 전환·종료 때 면역과 누적 타이머를 초기화한다.
- 진행 중인 공격과 씨앗·덩굴은 광폭화 진입 시 유지한다. 다음 자동 패턴 선택에는 기존 ‘항상 / 광폭화 전 / 광폭화 후’ 조건이 적용된다. 공격 시간표/패턴 간 대기를 자동으로 변경하지 않는다.

## 에디터에서 수치 변경

부패화 → 해당 Phase → **광폭화 생존전** 기믹을 선택한다. 기존 에디터의 공통 기믹 목록과 기본 속성 편집을 사용한다.

- **광폭화 진입 추가 체력 (`bonusHealth`)**: 기본 60.
- **체력 감소 간격 (`tickInterval`)**: 기본 1초.
- **간격당 감소 체력 (`healthPerTick`)**: 기본 1.

생존 시간은 `ceil((광폭화 직전 체력 + 추가 체력) / 간격당 감소 체력) × 감소 간격`이다. 이 기믹을 끄면 기존 광폭화 상태만 적용되며 공격으로 보스를 처치할 수 있다.

기믹은 페이즈당 하나만 사용한다. 광폭화를 발생시키는 기믹도 필요하다. 부패화는 기존 구역 성장의 **꽃잎 6개 모두 덩굴화 OR 중앙 덩굴화** 조건을 사용한다. 이 조건 자체는 변경하지 않았다.

공용 에디터 코드는 수정하지 않았다. 새 타입은 기존 자동 등록 메뉴에 나타난다. 기믹 격자 미리보기는 실제 보스 체력/클리어를 실행하지 않으므로 **생존전의 체력과 종료는 일반 전투 또는 기믹 합동 게임 실행에서 확인**한다. 사전 진행으로 처음 광폭화를 감지하면 그때 생존전이 시작되므로 긴 사전 진행이 실제 전투 경과 전체를 재현한다고 가정하지 않는다.

## 개발 연결과 검증

`IBossHealthMechanic`은 광폭화 진입 체력 변경, 플레이어 피해 차단, 누적 시간에 따른 체력 변경을 제공한다. 게임 호스트가 실제 체력/HUD와 처치 처리를 소유한다. 보스 이름 분기 없이 해당 기믹을 연결한 페이즈에서만 적용한다. 시간 감소는 다른 기믹의 플레이어 공격용 최소 체력 보호와 별개다.

`CompleteBossDefeat`를 경로 공격과 시간 만료가 함께 사용하여 클리어 기록·효과음·자원 정리를 동일하게 수행한다. 생존전에서 광폭화가 이미 감지된 뒤의 시간만 감소 대상으로 누적한다.

검증 기록과 미검증 범위는 [현재 패턴 목록](PatternHandoff/CurrentPatternCatalog.md)의 ‘부패화 광폭화 생존전’ 절을 참조한다.
