# 간편 공격 설계 — 팀원용 빠른 안내

보스 데이터를 더블클릭하고, 왼쪽에서 페이즈 아래의 패턴을 선택한다. 오른쪽의 **간편 공격 설계**가 기본 편집 화면이다. 기존의 개별 이벤트 편집은 **고급 이벤트 편집**에 남아 있다.

## 서로 다른 위치에 두 번 공격하기

1. **+ 다음 공격**을 누른다. 경고와 타격이 한 쌍으로 만들어진다.
2. **공격 이름**을 `왼쪽 공격`으로 바꾸고 오른쪽 맵의 왼쪽 타일을 클릭·드래그해 칠한다.
3. **경고 시작**을 `0`, **경고 길이**를 `1`로 정한다. 화면에 `경고 0초 → 타격 1초`가 표시된다.
4. 다시 **+ 다음 공격**을 누른다. `오른쪽 공격`이라고 이름 짓고 오른쪽 타일을 칠한다.
5. 두 번째 공격의 **경고 시작**을 `2`, **경고 길이**를 `1`로 정하면 3초에 오른쪽을 타격한다.
6. **미리보기 재생**으로 순서를 확인하고 상단의 **저장**을 누른다.

공격 목록의 행을 누르면 편집 대상이 바뀐다. 오른쪽 `편집 중: …`에 표시된 공격만 칠해진다. 시간표의 노란 막대는 경고, 빨간 막대는 타격 구간이다. 초록색 **테두리**는 선택 영역 안내이며 타일 내부의 재생 색상을 덮지 않는다. 필요하면 **선택한 공격 영역을 초록색 테두리로 표시**를 끈다. 미리보기 표시는 장애물 → 장판 → 경고 → 타격 → 이펙트 순서로 겹쳐 그리며, 같은 종류끼리는 나중에 생성된 표시가 위에 온다. 이는 에디터의 표시 순서이며 실제 공격 시점이나 피해 판정을 바꾸지 않는다.

## 랜덤 위치 하나를 기준으로 순차 공격하기

1. 패턴 위쪽의 **+ 위치 그룹**을 누르고 `위치 선택`을 **랜덤 이동 가능 타일**로 둔다.
2. 맵 가장자리 등 공격 영역이 잘릴 수 있는 곳을 제외하려면 **랜덤 후보 타일 직접 지정**을 켜고 **맵에서 후보 타일 칠하기**로 허용할 기준 타일을 칠한다. 제한을 끄면 이동 가능한 바닥 전체가 후보가 된다.
3. 첫 번째 공격의 **공유 위치 그룹**에서 만든 그룹을 선택한다. 이미 칠한 영역은 현재 미리보기 위치를 기준으로 상대 좌표로 바뀌므로 화면상의 위치는 유지된다.
4. **+ 다음 공격**으로 두 번째·세 번째 공격을 만든다. 새 공격은 현재 공격의 위치 그룹을 이어받는다. 각각 다른 상대 타일을 칠하고 **경고 시작** 시간을 순서대로 지정한다.
5. **랜덤 위치 다시 뽑기**와 **미리보기 재생**으로 여러 위치에서 확인한 뒤 저장한다. 하늘색 칸은 이번 미리보기의 그룹 기준 타일이다.

그룹 위치는 **패턴 실행 시작 시 한 번** 결정되고, 연결된 공격들은 그 위치만 공유한다. 각 공격의 경고·타격 타이밍과 타일 영역은 독립적이다. 그룹을 추가로 만들면 같은 패턴 안에서 또 다른 랜덤 기준 위치를 사용할 수 있다. `경고 시작 시 플레이어`와 달리 그룹의 **패턴 시작 시 플레이어**는 뒤늦게 시작하는 공격에도 처음 저장한 플레이어 위치를 사용한다.

## 자주 사용하는 작업

- **선택 공격 복제**: 영역과 연결된 연출을 복사하고 마지막 공격 뒤에 배치한다. 복사본의 영역은 원본과 별개다.
- **동시 공격 복제**: 복사본을 원본과 같은 시간에 배치한다. 다른 위치를 칠하면 동시에 서로 다른 곳을 공격한다.
- **이미 만들어진 공격 시간 변경**: 경고 시작과 길이를 바꾼다. 타격과 연결된 소리·이펙트·카메라 연출도 따라 움직인다.
- **영역 지우기**: 우클릭 또는 Shift+드래그. **선택 공격 영역 비우기**는 해당 공격의 영역만 비운다.
- **기존 십자 모양 편집**: **현재 모양을 유지하고 직접 칠하기**를 누른 후 원하는 타일을 추가/제거한다.
- **플레이어를 노리는 공격**: 위치 기준을 **경고 시작 시 플레이어**로 선택한다. 경고가 시작된 위치를 타격하며, 경고 중 플레이어를 계속 추적하지는 않는다.
- **소리 설정**: 경고 소리와 타격 소리에 AudioClip을 지정한다. 선택 사항이다.
- **되돌리기**: Ctrl+Z. 칠하기는 한 획, 복제와 삭제는 공격 묶음 단위로 되돌린다.
- **공격 끄기**: **이 공격 사용**을 끄면 연결된 경고·타격·연출을 함께 끈다.

## 알아둘 점

새 공격은 영역이 비어 있다. 반드시 맵을 칠하거나 십자·정사각형 등의 모양을 선택한다. **탈출 경로 확보**가 켜진 공격은 실행 시 플레이어가 피할 수 있도록 일부 타일이 제외될 수 있다.

**타격 구간**은 단발 타격 이벤트의 실행 시간이지 지속 피해 장판의 유지 시간이 아니다. 기존 피격 유예 설정은 유지된다. 지속 장판, 보스 애니메이션, 호출 패턴 등의 특수 이벤트는 고급 편집에서 추가한다. **패턴 최소 길이**보다 공격이 먼저 끝나면 남은 시간은 대기한다.

`P1_Cross_0`처럼 기존에 경고·타격·이펙트의 영역이 연결된 패턴도 하나의 공격으로 표시된다. 경고 영역을 칠하면 같은 공격의 타격과 이펙트에도 적용된다. 영역 연결용 내부 이름(Snapshot Key)은 간편 모드에서 입력할 필요가 없다.

키가 중복되어 연결이 모호하거나 경고 종료와 타격 시작이 떨어진 특수 구성은 자동으로 바꾸지 않는다. 이런 이벤트는 개별 이벤트 수로 안내되며 고급 편집에서 계속 실행·편집된다. 기존 생성기의 경고음·타격음·카메라는 시간과 이름이 명확히 일치할 때만 공격에 포함한다. 같은 시간의 여러 공격 중 어느 쪽에 속하는지 모호한 연출은 그대로 고급 편집에 남긴다. 단순히 패턴을 여는 것만으로는 저장 데이터가 변경되지 않는다.
