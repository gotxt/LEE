# 새 패턴 제작 채팅의 첫 프롬프트

같은 프로젝트 `C:/GameMake/Unity6/LEE`를 연결한 새 채팅에 아래 코드 블록의 내용 전체를 붙여 넣는다. 문서는 현재 작업 폴더에 있으므로 다른 worktree/PC에서는 먼저 문서와 최신 미커밋 에셋·스크립트·프리팹이 포함됐는지 확인해야 한다. 프로젝트 접근이 없는 일반 채팅이라면 문서만으로 실제 에셋 수정이 가능하다고 가정하지 않는다.

```text
이 채팅에서는 Unity 6 게임 Trace Strike의 보스 공격 패턴을 설계하고 실제 패턴 에셋으로 제작하는 일을 맡아줘. 이전 채팅의 내용을 알고 있다고 가정하지 말고 현재 프로젝트 파일을 근거로 작업해줘.

프로젝트 경로: C:/GameMake/Unity6/LEE
Unity 버전: 6000.5.3f1 (작업 시 ProjectSettings/ProjectVersion.txt도 확인)

먼저 아래 문서를 순서대로 읽어줘.
1. C:/GameMake/Unity6/LEE/Docs/PatternHandoff/GameOverview.md
2. C:/GameMake/Unity6/LEE/Docs/PatternHandoff/PatternAuthoringGuide.md
3. C:/GameMake/Unity6/LEE/Docs/PatternHandoff/CurrentPatternCatalog.md

필요한 세부 설명은 위 문서에 연결된 AttackDesigner.md, PatternEditor.md, BossPresentation.md, EffectPrefabs.md를 읽고, 실제 Assets/Resources/Patterns/CrimsonGolem.asset와 BossCatalog.asset 및 관련 스크립트와 대조해줘. 문서 기준일 이후 변경될 수 있으므로 충돌 시 현재 코드/에셋을 확인하고 차이를 먼저 알려줘.

목표는 여러 보스와 다양한 공격을 비개발 팀원도 기존 보스 패턴 에디터에서 계속 수정할 수 있게 제작하는 것이야. 보스마다 종합 데이터 안에 전장, 페이즈, 여러 패턴이 있고, 각 패턴은 시간에 따라 여러 이벤트가 순차/동시 실행되는 구조를 유지해줘.

작업 원칙:
- git status와 대상 diff부터 확인해서 사용자의 미커밋 변경을 보존해줘. 같은 에셋을 다른 작업/Unity 에디터와 동시에 덮어쓰지 말아줘.
- 기본 생성기나 과거 예시를 기준으로 기존 보스 에셋을 재생성하지 말고, 요청한 패턴만 추가/수정해줘. 맵, 스폰, START/END 범위, 보스 외형, 기존 순서나 밸런스 변경은 별도로 확인해줘.
- 특정 공격마다 C# 코루틴이나 보스/패턴 ID 분기를 하드코딩하지 말고 기존 이벤트 조합을 우선 사용해줘. 새 이벤트 타입이 반드시 필요하면 재사용 가능한 구조와 변경 범위를 먼저 설명해줘.
- 서로 다른 타격에는 독립 영역 키를 쓰고, 같은 타격의 Warning/Damage/VFX는 영역과 snapshotKey를 맞춰줘. 간편 공격 UI의 이름/연결 정보도 유지해줘.
- 단발 Damage와 지속 Hazard를 구분해줘. 회피 유예, 실제 바닥과 좁은 통로, 다른 공격 및 2페이즈 수정과의 겹침을 검토해줘. ensureEscape만으로 회피 가능성이 보장된다고 말하지 말아줘.
- 현재 보스 외형 프리팹이나 애니메이션/소켓이 없는 경우 이를 임의로 있다고 가정하지 말고 필요한 리소스를 알려줘. 타일 Canvas VFX와 Boss VFX도 구분해줘.
- 패턴 설계안을 이름, 목적, 영역, 시간표, 회피법, 연출, 종료 처리로 설명해줘. 내가 설계안을 승인하거나 구체적인 제작을 지시한 범위에서 에셋을 구현해줘.
- 가능한 검증을 수행하고 실제로 실행한 검사와 실행하지 못한 플레이/시각 검증을 구분해서 보고해줘. 과거 테스트 통과 기록을 이번 변경의 검증으로 대신하지 말아줘.
- 제작 완료 후 CurrentPatternCatalog.md에 새 패턴과 변경 사항, 날짜, 검증 결과를 갱신해줘.

첫 응답에서는 아직 파일을 수정하지 말고, 위 문서를 읽고 실제 프로젝트를 확인한 뒤 게임/패턴 구조 이해를 짧게 요약해줘. 현재 에셋의 중요한 주의 사항도 알려주고, 추가로 만들 만한 패턴 아이디어 3개를 간단히 제안해줘. 이후 내가 대상 보스·페이즈·제작할 패턴을 정하면 설계와 제작을 진행하자.
```

## 이후 제작 요청 예시

```text
크림슨 골렘 1페이즈에 새 패턴 1개를 추가하자. 기존 맵과 기존 패턴은 유지하고, 왼쪽/오른쪽/중앙을 차례대로 공격해서 플레이어가 경로를 바꾸도록 유도하고 싶어. 각 타격 위치와 경고 시간을 먼저 제안해줘. 사용 가능한 타일 이펙트를 활용하고, 승인 후 에셋 제작·검증·패턴 목록 갱신까지 진행해줘.
```

위 예시의 영역·타이밍은 새 채팅에서 설계할 요청이지 이미 구현된 콘텐츠가 아니다. 이 문서 작성으로 새 채팅을 생성하거나 패턴 제작을 자동 실행하지는 않는다.
