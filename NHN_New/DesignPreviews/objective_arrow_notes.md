# 플레이어 주변 목표 방향 화살표

적용 프로젝트: `D:\codex\NHN\NHN_New`.

- 시작 타일을 밟기 전: 시작 타일 방향 안내.
- 시작 타일을 밟아 경로 기록이 시작된 후: 종료 타일 방향 안내.
- 경로 중복으로 기록이 초기화된 경우: 시작 타일로 안내 복귀.
- 공격 후 시작·종료 타일이 재배치된 경우: 새 시작 타일로 즉시 목표 갱신.
- 시작 타일 위에서 리스폰한 경우: 경로 기록이 이미 시작되므로 종료 타일 안내.
- 화살표는 캐릭터 둘레의 일정 반경에서 목표 방향으로 부드럽게 회전. 무작위로 공전하지 않음.
- 흰색 화살촉과 검은 픽셀 테두리는 첨부 예시를 참고한 Unity UI 도형으로 제작. 예시의 회색 배경은 표시하지 않음.
- 타이틀, 사망, 클리어, 페이즈 전환 중에는 숨김. 기본 공격 튜토리얼에서는 시작·종료 타일을 안내하고, 특수 발판 학습 단계에서는 숨김.
- 이동과 피해 판정, 17×17 맵, 카메라, 보스 체력은 변경하지 않음.

실행: `Builds/Windows/TraceStrike.exe`.

## 검증 결과

- Windows 빌드 성공: `objective_arrow_build.log`.
- EditMode 테스트 56개 통과, 실패 0개: `objective_arrow_test_results.xml`.
- 시작 목표 방향 검증 통과: `objective_start_player.log`, `objective_arrow_start.png`.
- 시작 타일 진입 후 종료 목표 방향 검증 통과: `objective_end_player.log`, `objective_arrow_end.png`.
- 두 실행 화면에서 캐릭터와의 간격, 회색 배경 없이 표시되는 픽셀 화살촉, 목표 방향을 확인.
