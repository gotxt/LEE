# 캐릭터 근접 추적 시점 · 확장 맵

적용 대상: `D:\codex\NHN\NHN_New`만 변경. 기존 `NHN` 프로젝트는 유지.

## 변경 사항

- 참고: https://www.youtube.com/watch?v=hr51pNRtJeM&t=10s 의 캐릭터 중심 시점과 화면 밖까지 이어지는 바닥 표현.
- 최신 사각 타일은 그대로 유지. 11×11 / 89칸에서 17×17 / 221칸으로 이동 가능한 맵을 확장.
- 가로·세로 동일한 비율로 둥근 외곽을 확장하며, 대각선 격자나 다른 맵 형태로 바꾸지 않음.
- 셀 확대 배율 1.62 → 2.05, 캐릭터의 셀 대비 표시 비율 0.58 → 0.78. 캐릭터는 직전 빌드보다 화면에서 약 1.7배 크게 표시.
- 한 칸 이동의 실제 판정은 유지하고, 표시 위치만 0.11초 동안 부드럽게 이동.
- 이동 방향을 약간 앞서 비추는 추적 카메라. 맵 가장자리에서는 카메라 이동을 제한해 바깥 빈 공간 노출을 줄임.
- 폭발 화면 흔들림과 이동 시 캐릭터 반응을 카메라 추적과 분리해 복귀 시 화면 튐을 방지.
- 중앙 3×3 고대미지 구역, 칸별 대미지, 보스 체력 150 / 150, 수정 공격 주기는 유지.
- 마름모 보스 문양 반경은 확대 맵에 맞춰 3 / 5칸 → 5 / 8칸으로 비례 조정. 가로·세로 패턴은 확장된 필드 전체를 사용.

## 확인 파일

- `close_camera_play.png`: 실제 플레이 확대 시점.
- `expanded_arena_overview.png`: 전체 221칸 맵을 보기 위한 축소 미리보기. 게임의 기본 시점이 아님.
- `close_camera_edge.png`: 맵 끝의 카메라 제한과 캐릭터 표시 확인.
- Windows 실행 파일: `Builds/Windows/TraceStrike.exe` (같은 폴더의 데이터 및 DLL과 함께 유지).

## 검증

- Windows 16:9 빌드 성공: `close_camera_build.log`.
- 프로젝트 EditMode 테스트 51개 통과, 실패 0개: `close_camera_test_results.xml`.
- 실행 빌드의 부드러운 두 칸 이동, 카메라 추적 및 화면 흔들림 복귀 검증 통과: `close_camera_player.log`.
- 맵 하단 경계에서 캐릭터 전체가 화면 안에 남는 검증 통과: `close_camera_edge_player.log`.
- 실제 플레이 화면, 전체 맵 축소 화면, 가장자리 화면을 각각 캡처하여 확인.
